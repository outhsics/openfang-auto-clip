## 正文版本

```text
最近把 OpenFang Auto Clip 做到一个更适合公开展示的阶段，就先把 v0.3.0 发出来了。

它现在最值得看的不是“全自动短视频帝国”，而是一个更稳的本地视频再利用工作流：

1. local-first，不走托管 SaaS 叙事
2. 有可复现的 synthetic benchmark
3. 有已经能跑通的 FFmpeg-based Level 1 转换
4. 有本地 Web manager 和任务历史
5. release 不只是 notes，还会带 benchmark report、storyboard、preview、launch 文案和 social preview

我现在更在意的是两件事：
- 仓库能不能被快速验证
- 文档和实际能力是不是一致

最新一次 benchmark：
- 18 秒 synthetic media
- 3 个 clips
- 总耗时 9.8s

如果你也在看本地化、可复现、工程化的视频自动化方向，可以直接看这个 release：
https://github.com/outhsics/openfang-auto-clip/releases/tag/v0.3.0

仓库：
https://github.com/outhsics/openfang-auto-clip
```
