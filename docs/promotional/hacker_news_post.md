Hi HN,

I've been working on an open-source video automation pipeline that addresses a common pain point: turning long-form content into short clips without:

- Uploading your videos to cloud services (privacy concern)
- Paying expensive SaaS fees ($20-100/month)
- Being locked into black-box features

## What is OpenFang Auto Clip?

It's a **local-first** video automation tool that:

✅ **Runs entirely locally** - Your content never leaves your machine
✅ **Fully customizable** - Built with Python + FFmpeg, you control everything
✅ **100% free & open-source** - MIT licensed, no API costs
✅ **Privacy-preserving** - Works completely offline
✅ **Production-ready** - Includes benchmark, evaluation suite, and web UI

## Quick Demo (5 seconds)

```bash
pip install openfang-auto-clip
python3 auto_clip.py --quick-demo
```

## Use Cases

- **Content creators**: Turn YouTube videos into TikTok/Shorts/Reels clips
- **Podcasters**: Extract highlights from long episodes
- **Developers**: Automate video workflows with Python
- **Marketing teams**: Batch process content for multiple platforms

## Tech Stack

- Python 3.9+
- FFmpeg (video processing)
- yt-dlp (video downloading)
- Local-first architecture (no cloud dependencies)
