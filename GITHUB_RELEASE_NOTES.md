# OpenFang Auto Clip v0.2.0 Release Notes

Release date: `2026-02-28`

## Release Focus

Version `v0.2.0` introduced the core local workflow for video downloading, clip export, and Level 1 visual remix.

## Included In This Release

- Level 1 visual remix path
- multi-platform vertical export
- automated video download flow
- FFmpeg processing pipeline
- bilingual project documentation

## Positioning Guidance

- emphasize local-first workflow and reproducible benchmark value
- do not market Level 2 or Level 3 as finished commercial capability
- describe copyright handling as workflow and risk reduction, not a legal guarantee
