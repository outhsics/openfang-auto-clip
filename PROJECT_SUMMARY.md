# Project Summary

## Snapshot

- Name: OpenFang Auto Clip
- Status: actively iterating
- Positioning: local-first video repurposing and short-clip workflow
- License: MIT

## Core Value

- turn long videos into platform-ready short clips
- use Level 1 visual remix to reduce direct-repost similarity
- improve repo credibility with benchmark, storyboard, launch-kit, and release artifacts

## What Is Shipped

- main CLI flow
- Level 1 visual remix
- local web manager with persisted task state
- synthetic benchmark demo
- storyboard output
- launch-kit generation
- tag-based release automation

## Current Boundaries

- Level 2 now ships a transcript-to-script package milestone, while Level 3 remains roadmap-only
- no hosted cloud offering
- commercial credibility still depends on stronger demos and user proof

## Near-Term Priorities

- bilingual docs and status hygiene
- stronger benchmark and distribution assets
- clearer release process
- more honest public positioning
