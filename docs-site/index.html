Workflow

Three commands to evaluate the project

1. Environment

./auto_clip.sh --doctor

Confirms Python, ffmpeg, yt-dlp, config path, and output directory readiness.

2. Benchmark

python3 scripts/run_demo_benchmark.py

Generates clips, `benchmark_report.json`, `preview.png`, and `storyboard.png` with synthetic media.

3. Launch copy

python3 scripts/generate_launch_kit.py --report examples/benchmark/sample_benchmark_report.json

Builds launch-ready Markdown from a benchmark report so your promo copy stays anchored to real output.
