# Showcase: Local Web Manager Console

## Goal

Show the repo as a local operator console instead of only a command-line utility.

## Command

```bash
./start_web_manager.sh
```

Open `http://localhost:5000`.

## What To Demonstrate

- task launch from the browser
- URL validation before processing
- local task history
- access to output directories without a hosted backend

## Why It Matters

- makes the repo easier to demo to non-terminal users
- gives a visual entry point for creators and operators
- reinforces the local-first story without pretending to be SaaS

## Best Use

- screen-recorded product walkthroughs
- internal team demos
- comparison against cloud-first clip tools
