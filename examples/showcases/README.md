# Showcase Demos

These demos are designed for launch posts, repo walkthroughs, and future AI handoff.

## Included Showcases

- [benchmark_release_proof.md](benchmark_release_proof.md): fastest proof that the repo is real and reproducible
- [dry_run_intake.md](dry_run_intake.md): safest operator intake flow before touching real media
- [web_manager_console.md](web_manager_console.md): local UI workflow for demos and daily operation

## Selection Guide

- Use the benchmark showcase when introducing the repo publicly
- Use the dry-run showcase when talking about operator safety and evaluation flow
- Use the web manager showcase when you need a UI-driven demo
- Use [../evaluation/README.md](../evaluation/README.md) when you want the full current evaluation map
