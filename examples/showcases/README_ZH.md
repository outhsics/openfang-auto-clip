# Showcase Demo 列表

这些 demo 用来支撑对外发布、仓库讲解，以及后续 AI 接手。

## 当前包含

- [benchmark_release_proof_ZH.md](benchmark_release_proof_ZH.md)：最快证明仓库真实可复现
- [dry_run_intake_ZH.md](dry_run_intake_ZH.md)：先验环境和流程的最安全入口
- [web_manager_console_ZH.md](web_manager_console_ZH.md)：适合演示和日常操作的本地 UI 路径

## 怎么选

- 对外介绍仓库时优先用 benchmark showcase
- 讲 operator safety 或评估流程时用 dry-run showcase
- 需要可视化演示时用 web manager showcase
- 如果你想看当前完整评估入口，直接看 [../evaluation/README_ZH.md](../evaluation/README_ZH.md)
