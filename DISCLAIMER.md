# Disclaimer

OpenFang Auto Clip is a local media processing tool. It is not legal advice and it does not certify any workflow as copyright-safe.

## What this repository does

- helps download source media with user-supplied URLs
- applies local FFmpeg-based transformations
- slices processed media into vertical clips
- provides benchmark and release collateral for evaluation

## What this repository does not guarantee

- that transformed output is legal to publish in your jurisdiction
- that platform moderation systems will treat the output as original
- that Level 2 or Level 3 roadmap ideas are production-ready today
- that commercial use is low risk without separate review

## Your responsibility

You are responsible for:

- confirming rights to source material

## Positioning rule for maintainers

When describing the project publicly:

- describe Level 1 as a working local remix path
