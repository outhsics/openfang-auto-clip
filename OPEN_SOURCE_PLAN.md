# Open Source Plan

## Goal

Build OpenFang Auto Clip into a credible local-first media automation project with a realistic path toward `1000 GitHub stars`.

## Core Thesis

The repo is unlikely to reach `1000 stars` as "another shorts automation tool". It needs to win as:

`local-first video repurposing pipeline with reproducible benchmark, honest scope, and operator-friendly tooling`

## Success Metrics

### Foundation Metrics

- GitHub license correctly detected as MIT
- Discussions enabled
- README and docs match actual shipped scope
- benchmark can be run by a new visitor in minutes

### Activation Metrics

- more visitors complete benchmark or dry-run successfully
- issues and discussions show real usage, not only vague interest
- releases ship with demo artifacts, not only release notes

### Growth Metrics

- `100 stars`: credibility and first wave of community validation
- `300 stars`: repeatable release and content cadence
- `1000 stars`: multiple distribution channels and a clear category narrative

## Workstreams

### 1. Credibility

- keep README grounded
- remove unsupported claims
- publish governance and support policies
- keep benchmark outputs reproducible

### 2. Product Surface

- strengthen Level 1 workflow
- improve benchmark and report quality
- turn roadmap ideas into smaller implemented milestones

### 3. Distribution

- every release needs benchmark proof, visual assets, and a concrete story
- target creator-tooling, self-hosted, ffmpeg, and agent-workflow audiences
- use discussions and showcase threads as social proof

## Things To Avoid

- marketing Level 2 or Level 3 as done
- promising legal guarantees
- adding cloud or SaaS claims before local reliability is strong
- measuring progress only by stars instead of evaluation quality

## Near-Term Execution

1. finish repo hardening
2. ship a credibility-focused release
3. publish one benchmark-driven launch thread in English and one in Chinese
4. collect operator feedback and fold it into the next release
